## 1. 项目概述

### 1.1 定位

一款纯静态网页格斗游戏：**同一键盘本地双人对战**，2D 一对一，玩法参照《拳皇》（KOF）系列的节奏与系统——冲刺、翻滚、吹飞、防御取消、能量槽管理、连段修正、指令投。无网络、无 AI，即开即打。

- 平台：桌面浏览器（Chrome / Edge / Firefox）
- 形态：`https://<host>/fighter/` 直接游玩，无构建、无外部依赖、可离线
- 语言：界面全中文，招式指令采用格斗游戏通用记号

### 1.2 核心体验支柱

1. **两人一键盘就能开打**：无需手柄、注册或房间，30 秒进入对战。
2. **KOF 式攻防节奏**：前冲后撤、翻滚读招、防御取消反打、靠能量槽做资源交换。
3. **看得懂的深度**：帧数据、硬直、连段修正透明呈现（帮助与结算中可见），新手可莽、老手可算。

### 1.3 与仓库既有约定的一致性

- 每游戏独立目录，原生 HTML/CSS/JS，无 npm 依赖、无 CDN
- Canvas 2D 渲染 + 固定逻辑帧率，WebAudio 合成音效
- 中文 UI、`localStorage` 持久化、暂停与失焦处理、版本号标注
- 门户 `index.html` 增加入口（实现阶段完成）

## 2. 范围

### 2.1 v1.0 包含

- 本地双人 1v1，三局两胜，99 秒回合计时
- 4 名可选角色（均衡 / 速度 / 力量投技 / 牵制），支持镜像同选
- 3 张舞台（街市 / 古寺 / 工厂），含视差与动态元素
- 完整战斗系统：通用通常技、特殊技、必杀技、超必杀、EX 版、MAX 状态、投技、防御、防御取消、翻滚、吹飞、眩晕、破防、受身
- 能量槽（3 格）与跨局继承规则
- 选人 → 选台 → 对战 → 结算 → 再战 全流程
- 程序化 BGM 与全套合成音效，静音持久化
- 键位速查、暂停菜单、战绩（双方累计胜场）持久化

- 网络对战、AI 对手

- 移动端触控操作（仅做"需键盘"提示）
- 3v3 组队赛制、援助/换人系统
- 键位自定义、键位冲突检测
- 录像回放、训练模式（帧表查看、假人）
- 角色解锁、剧情、皮肤商店

## 3. 术语与输入记号

| 记号 | 含义 |
|---|---|
| 帧（f） | 逻辑帧，固定 1/60 秒 |
| 1–9 | 数字键盘方向记号，相对角色朝向（6=前，4=后，2=下，8=上，3=前下） |
| LP / LK / HP / HK | 轻拳 / 轻脚 / 重拳 / 重脚 |
| P / K | 任一 punch / kick（EX 输入用双键） |
| AB | 翻滚（轻+重闪避，本作独立按键） |
| CD | 吹飞攻击（本作独立按键） |
| BC | MAX 状态激活 |
| 发生 / 持续 / 硬直 | 招式判定开始帧数 / 判定存在帧数 / 可行动前剩余帧数 |
| 有利帧 | 命中或防御后，己方可行动帧数减对方可行动帧数 |

指令示例：`236P` 波动拳式，`623P` 升龙式，`214K`，`63214P` 指令投，`[4]6P` 蓄力技，`236236P` 双转超必杀。

## 4. 对局流程与状态机

### 4.1 全局状态

```
标题 title → 主菜单 menu → 角色选择 select → 舞台选择 stage
→ 回合开场 intro → 对战 battle ⇄ 暂停 pause
→ KO 演出 ko → 结算 result → 再战 rematch / 回菜单 menu
```

### 4.2 回合规则

| 项 | 规则 |
|---|---|
| 回合时长 | 99 秒，最后 10 秒计时数字闪烁并播放滴答音 |
| 胜负 | 先赢 2 局者胜（三局两胜） |
| KO | 一方 HP ≤ 0，立即进入 KO 演出 |
| 时间到 | 剩余 HP 百分比高者胜该局 |
| 双 KO | 该局作废重赛，不计胜局 |
| 时间到且 HP 相同 | 同双 KO，作废重赛 |
| 完美胜 | 满血获胜在结算中标注 "PERFECT" |

### 4.3 局间与跨局继承

| 状态 | 回合间 | 整场结束后 |
|---|---|---|
| HP | 重置满血 | 重置 |
| 能量槽 | **保留** | 清零 |
| MAX 状态 | 解除 | 解除 |
| 眩晕槽 / 防御槽 | 清零 | 清零 |
| 回合点 | 保留 | 清零 |

### 4.4 开场 / 演出时序

- 回合开场：`ROUND N` 显示 60f → `FIGHT!` 40f，期间禁止操作
- KO：顿帧 40f → 0.3 倍慢镜 60f → `K.O.` 大字 90f → 30f 后进入结算
- 超必杀：发动时冻结对手 30f，全屏 cut-in 45f，背景压暗
- 结算：胜者胜利姿势 + 台词条，展示 最大连击 / 剩余时间 / 造成总伤害 / 双方累计胜场

## 5. 操作需求

### 5.1 P1 键位

| 功能 | 按键（e.code） |
|---|---|
| 移动 | A / D（KeyA / KeyD） |
| 蹲 | S（KeyS） |
| 跳 | W（KeyW） |
| 轻拳 LP | J |
| 轻脚 LK | K |
| 重拳 HP | U |
| 重脚 HK | I |
| 翻滚 AB | L |
| 吹飞 CD | H |
| 投技 | J + K 同按（≤2f 容差） |

### 5.2 P2 键位（两套并行生效，无需切换）

| 功能 | 主方案（小键盘） | 备选（无小键盘机型） |
|---|---|---|
| 移动 | ← → | ← → |
| 蹲 / 跳 | ↓ / ↑ | ↓ / ↑ |
| 轻拳 LP | Numpad1 | `,`（Comma） |
| 轻脚 LK | Numpad2 | `.`（Period） |
| 重拳 HP | Numpad4 | `/`（Slash） |
| 重脚 HK | Numpad5 | `;`（Semicolon） |
| 翻滚 AB | Numpad0 | `'`（Quote） |
| 吹飞 CD | Numpad3 | `[`（BracketLeft） |
| 投技 | Numpad1+2 | `,` + `.` |

P2 主备键位同时映射到同一动作，按下任意一套即生效；两套键位与 P1 键位无重叠。

### 5.3 系统键

| 功能 | 按键 |
|---|---|
| 确认 / 开始 | Enter |
| 暂停 / 返回 | Esc |
| 静音开关 | M |
| 结算界面再战 | R（或 Enter） |
| 操作说明 | 仅菜单 / 暂停面板入口，无热键 |

### 5.4 输入判定要求

| 项 | 要求 |
|---|---|
| 键值来源 | 一律使用 `e.code`，忽略 `e.key`（键盘布局无关） |
| 默认行为 | 所有已映射键在游戏内 `preventDefault`（含方向键、空格、小键盘） |
| 重复事件 | 攻击键 `e.repeat` 忽略，方向键按住持续生效 |
| 输入缓冲 | 攻击指令 8f 缓冲；方向指令逐段识别（见下） |
| 滚动技窗口 | 236 / 623 / 214 每步 ≤12f；63214 每步 ≤10f；236236 两段各 ≤14f；蓄力 [4]6 需后方向蓄力 ≥40f |
| 冲刺 | 12f 内连续两次同向（66 / 44）触发前冲 / 后撤 |
| 跳跃 | 起跳键按住 ≤6f 为小跳（高度 60%），>6f 为普通跳；前冲中按跳为超级跳 |
| 同按容差 | 投技、EX 双键判定窗口 2f |
| 同时输入 | 双方按键互不干扰，支持至少 12 键同时按下无丢失（受硬件键盘矩阵限制，见 17 章） |

### 5.5 键盘实现约束

- 战斗内禁止浏览器默认滚动、查找、缩放等行为
- 失焦（`blur`）与标签页隐藏（`visibilitychange`）自动暂停
- 暂停恢复后不累积时间、不重复触发逻辑循环
- 触屏设备（`pointer: coarse`）首次触碰时显示"本作需键盘操作"提示，不阻止页面显示

## 6. 战斗系统通用规则

### 6.1 基础物理

| 项 | 规则 |
|---|---|
| 逻辑分辨率 | 960 × 540，地面基线 y = 480，角色高约 240px |
| 重力 / 起跳 | 重力 0.9 px/f²，普通跳初速约 20 px/f，滞空约 45f |
| 推箱 | 双方身体宽 70px，不可重叠；角落处进攻方被反推 |
| 朝向 | 自动面向对手；出招、倒地、受身过程中朝向锁定 |
| 换边 | 空中跨越对手后落地自动转向；允许空中换边（crossup） |
| 空中规则 | 空中不可防御；每次跳跃限 1 次空中通常技；部分角色有空中必杀 |

### 6.2 防御

- 站立防御：后退方向（4）自动防御中段 / 上段
- 蹲防：4+2，防御下段与中段，**不可防中段特殊技（overhead）**
- 防御中不可移动，防御硬直由招式数据决定
- 空中不可防御

### 6.3 防御槽（破防）

| 项 | 数值 |
|---|---|
| 范围 | 0–100 |
| 增长 | 每次防御成功 + 该招式伤害 × 0.10 |
| 破防 | 满 100 触发破防硬直 40f，槽清零 |
| 衰减 | 1.5s 内无防御行为后，以 4/s 衰减 |

### 6.4 眩晕槽

| 项 | 数值 |
|---|---|
| 范围 | 0–100 |
| 增长 | 被命中 + 该招式伤害 × 0.12 |
| 眩晕 | 满 100 进入眩晕 120f，槽清零 |
| 衰减 | 60f 未再受击后以 6/s 衰减 |
| 提前解除 | 眩晕中连打任意攻击键，最短可减至 60f |

### 6.5 能量槽（3 格制）

| 项 | 数值 |
|---|---|
| 范围 | 0–300（每格 100） |
| 命中获取 | 伤害 × 0.35 |
| 受击获取 | 伤害 × 0.25 |
| 防御获取 | 伤害 × 0.15 |
| 空挥获取 | 每招 +2（仅通常技，防刷槽） |

| 消耗项 | 槽耗 |
|---|---|
| EX 版必杀（指令 + 同系双键） | 100 |
| 超必杀 | 100 |
| SDM 超必杀 | 200（MAX 中 100） |
| MAX 激活（BC） | 100 |
| 防御取消（GC） | 100 |

### 6.6 MAX 状态

- 持续 600f（10 秒），HUD 显示计时条
- 期间：通常技可直接取消必杀技；EX 版免费；SDM 降为 100
- 结束或回合结束时解除

### 6.7 连段与修正

| 项 | 规则 |
|---|---|
| 连段修正 | 第 n 击伤害倍率 = max(0.3, 1 − 0.1 × (n−1))，HUD 显示连击数与当前倍率 |
| 破招（counter） | 在对手招式发生帧内命中：伤害 ×1.2，命中硬直 +2f，画面标记 COUNTER |
| 顿帧 | 轻攻击 6f / 重攻击 9f / 必杀 10f / 超必杀 14f，双方冻结 |
| 同帧互中 | 双方同时命中判 trade：各自吃伤害，互不打断 |
| 投 vs 打击 | 同帧成立时投技优先 |

### 6.8 投技

| 项 | 规则 |
|---|---|
| 普通投 | 发生 3f，距离 ≤70px，伤害 110（岩 130），可拆投 |
| 拆投 | 被投方在 10f 内同按投键 → 双方推开，无伤害 |
| 指令投 | 发生 6f，不可拆投，命中后倒地 |
| 投技对空 | 不可投空中角色 |

### 6.9 倒地与受身

- 倒地起身 30f，起身全程无敌
- 倒地瞬间按 2（蹲）快速起身，减为 15f
- 受身：落地前按 AB，可向左/右滚动受身，消耗 0 槽，受身过程无敌至滚动结束
- 浮空追击上限：单次连段内对同一目标最多 1 次倒地追打

### 6.10 冲刺、翻滚、吹飞

| 动作 | 数据 |
|---|---|
| 前冲 | 24f，6f 后可取消通常技/必杀，前冲中可超级跳 |
| 后撤 | 22f，1–8f 无敌 |
| 翻滚 AB | 26f，1–20f 无敌，按 4/6 决定方向，结束硬直 5f |
| 吹飞 CD | 发生 14f，命中击飞；破招时撞墙反弹并允许追打 |

### 6.11 防御取消（GC）

- 防御硬直中按 CD 或 AB 且能量 ≥100：消耗 100 槽，执行吹飞 / 翻滚并附加 1–10f 无敌
- GC 吹飞命中后不形成连段（仅解围）

### 6.12 取消路线

1. 通常技链：LP → LK → HP → HK，每级每连段限一次
2. 特殊技（指令通常技）→ 必杀技
3. 必杀技 → 超必杀（每连段限 1 次超必杀）
4. MAX 状态追加：通常技 → 必杀技
5. 禁止：超必杀取消、投技取消、弹墙后无限连（见 6.7 修正）

### 6.13 飞行道具

- 命中或成功防御后消失；投技判定不可作用于飞行道具
- 双方弹道相撞时同归于尽
- 冰墙等设置型道具按 8.4 单独定义

## 11. 视觉与动效需求

### 11.1 美术方向

- 矢量剪影 + 霓虹描边风格：角色为分部位绘制的胶囊体（头/躯干/上臂/前臂/大腿/小腿）骨架姿态动画，按玩家色描边
- 每角色专属姿态库：待机呼吸、走、冲刺、后撤、小跳/大跳、蹲、防御、受击、浮空、倒地、起身、眩晕、胜利、KO
- 每招式 2–4 个关键姿态（起手 / 命中 / 收招），姿态间插值 4–8f，关键帧切换瞬间加 1–2px 前倾（"张力帧"）
- 动作可读性优先：发生帧姿态收束，持续帧伸展，硬直帧松弛

### 11.2 特效

| 特效 | 说明 |
|---|---|
| 命中火花 | 按伤害分级（轻 4 片 / 重 8 片 / 必杀 12 片），命中点扩散 |
| 防御火花 | 蓝白色弧形，附带格挡金属声 |
| 残影 | 冲刺、后撤、闪身、超必杀位移期间每 3f 采样 |
| 尘土 | 起跳、落地、冲刺起终点 |
| 超必杀 | 全屏冲击线 + 角色立绘 cut-in 45f + 背景压暗 |
| 震屏 | 轻 4px / 重 7px / KO 10px，衰减 200ms |
| 闪白 | 破防、GC、KO 瞬间 |
| 慢镜 | KO 后 0.3 倍速 60f |

- 所有震动/闪白/热浪受 `prefers-reduced-motion` 控制可关闭

## 13. 技术需求

### 13.1 目录与文件

```
fighter/
  index.html      # 结构 + 内联少量布局样式
  style.css       # 全部样式
  js/core.js      # 游戏循环、状态机、resize、暂停
  js/input.js     # 键盘映射、缓冲、指令识别
  js/combat.js    # 物理、判定、槽、回合规则
  js/chars.js     # 4 角色帧表与姿态数据
  js/render.js    # 角色/舞台/特效/HUD 绘制
  js/audio.js     # 合成音效与 BGM
  js/ui.js        # 菜单、选人、结算、暂停 DOM 交互
```

- 传统 `<script>` 顺序加载，无模块化构建、无依赖、无网络请求
- 与仓库既有游戏保持同构：单目录、可直接静态托管

### 13.2 渲染与循环

| 项 | 要求 |
|---|---|
| Backing store | 逻辑 960×540，`devicePixelRatio` 上限 2，等比 letterbox 居中 |
| 主循环 | 单 `requestAnimationFrame`；固定 60Hz 逻辑步长（累加器），`dt` 钳制 ≤0.05s |
| 暂停 | 暂停期间不推进逻辑、不累积时间，渲染可冻结或保留静态画面 |
| 缓存 | 渐变、光晕、舞台底图预烘焙；热路径（判定/槽）零分配 |
| 分辨率适配 | 窗口缩放与旋转通过 ResizeObserver 重设 canvas，逻辑坐标不变 |

### 13.3 数据驱动

- 招式帧数据、姿态序列、伤害/槽/硬直全部集中于 `chars.js` 数据表，逻辑层只消费数据
- 帧数据字段至少包含：发生、持续、硬直、伤害、命中硬直、防御硬直、取消标签、槽耗、无敌帧、判定盒

### 13.4 持久化（localStorage）

| 键 | 内容 |
|---|---|
| `nfMuted` | `'1'` / `'0'` |
| `nfWins` | JSON `{p1, p2}` 累计胜场 |
| `nfLastChars` | JSON 上次选角 |
| `nfStage` | 上次舞台（含 `random`） |

### 13.5 性能预算

- 720p / 1080p 窗口、中端集显下 ≥55fps；单帧逻辑 ≤4ms，渲染 ≤8ms
- 同屏粒子 ≤400；同屏飞行道具 ≤4
- 页面零控制台报错、零外部请求、断网可玩

### 13.6 兼容性

- Chrome / Edge / Firefox 最近两个大版本
- 桌面分辨率 1280×720 起；不小于 1024×600 时布局不破版

## 14. 数值与平衡目标

| 项 | 目标 |
|---|---|
| HP / 回合 | 1000 / 99s |
| 平均回合时长 | 55–75s（含演出） |
| 目标 TTK | 3–4 套完整连段击倒（单套 250–350 伤害） |
| 单次连段上限 | 6 击（修正后收益递减） |
| 各角色理论胜率 | 45%–55%（4 角色两两对局） |
| 起始距离 | 双方相距 480px（屏幕中线两侧 240px） |
| 边角压力 | 角落防守方需有 GC / 翻滚等可选项，避免无限循环压制 |

- 平衡调整只允许改 `chars.js` 数据表与第 14 章常量，不改逻辑代码
- 提供隐藏调试开关（URL 参数）显示判定盒与帧计数，仅供开发验收，不暴露给普通玩家

## 17. 风险与对策

| 风险 | 对策 |
|---|---|
| 同键盘按键冲突（ghosting） | 键位跨行分散；P2 小键盘为主方案、备选键独立；AC-01 实机验证并记录硬件限制 |
| 判定公平性争议 | 固定帧序：输入 → 物理 → 判定 → 结算；trade / 投优先规则明确；隐藏调试帧计数 |
| 平衡工作量 | 全数据驱动，改表不改码；先锁定 TTK 与连段上限 |
| 范围膨胀 | 2.2 节清单即为不做清单；3v3、AI、网战一律延后 |
| 程序化音频单薄 | 每事件至少双层（噪声 + 音调），BGM 循环加淡入淡出避免接缝 |
| 性能不足 | 粒子/道具上限、渐变缓存、热路径零分配，M1 起持续监控 |
